# CS 175 Poker Agent

A heads-up Texas Hold'em poker agent built from scratch for UCI CS 175 (Project in AI, Spring 2026). Implements Monte Carlo hand strength estimation, a pot-odds decision policy, and opponent modeling across four milestones.

No external poker libraries — hand evaluation, game logic, and all agents are implemented by hand.

---

## Getting Started

### Prerequisites

- Python 3.10+
- Install dependencies:

```bash
pip install -r requirements.txt
```

`numpy` and `matplotlib` are optional but recommended. The Monte Carlo estimator falls back to pure Python if numpy is unavailable; plots in Milestone 4 require matplotlib.

### Project structure

```
poker_agent/          # Core library
    card.py           # Card, Deck primitives
    hand_eval.py      # 5–7 card hand evaluator
    game.py           # Texas Hold'em game environment
    monte_carlo.py    # Monte Carlo EHS estimator
    simulation.py     # Multi-hand simulation engine
    stats.py          # Session logging and statistics
    agents/
        base.py           # Abstract Agent interface
        random_agent.py   # Uniform random baseline
        rule_based_agent.py  # Chen formula preflop heuristic
        ehs_agent.py      # Monte Carlo + pot-odds agent
docs/                 # Milestone documentation
results/              # Output plots (generated by Milestone 4)
v1.py                 # Milestone 1 test script
v2.py                 # Milestone 2 test script
v4.py                 # Milestone 4 test script
v5.py                 # Milestone 5 round-robin benchmark
```

## Running the Milestones

Each milestone has a self-contained test script. Run them in order — each validates the components built so far.

### Milestone 1 — Environment & Baseline Agents

```bash
python3 v1.py
```

Runs 16 hand evaluator unit tests, traces 5 sample hands, then runs a 10,000-hand simulation (Random vs Random). Takes ~5 seconds.

Expected output:
```
MILESTONE 1 COMPLETE
Unit tests:  ALL PASS
Hands run:   10,000
Errors:      0
```

### Milestone 2 — EHS Agent (Monte Carlo + Pot Odds)

```bash
python3 v2.py
```

Verifies EHS estimates for known hands (AA ~0.85, 72o ~0.35), checks for pot-odds policy violations, then runs a 10,000-hand simulation (EHSAgent vs Random). Takes ~60–90 seconds.

Expected output:
```
MILESTONE 2 COMPLETE
EHS sanity (AA~0.85, 72o~0.35): PASS
Pot-odds violations:            0 (PASS)
EHSAgent mbb/hand vs Random:   +XXXX.X (PASS)
```

### Milestone 4 — Tuning, Evaluation, and Plots

```bash
python3 v4.py                  # full pipeline (~25 min)
python3 v4.py --parallel --jobs 8   # parallel grid search + evaluations
python3 v4.py --skip-grid --n-samples 500 --raise-threshold 0.15
python3 v4.py --grid-hands 500 --eval-hands 1000 --no-plots
```

`--parallel` uses multiprocessing for the 9 grid configs and 3 final evaluations (sequential by default). EHS win/loss stats are collected during the RuleBased evaluation — no extra simulation pass.

### Milestone 5 — Round-Robin Benchmark (`v5.py`)

Heads-up round-robin across **RuleBased**, **EHS**, **Full**, **TAG**, and **LAG**. Compares EHS and Full against each other and every other archetype. Full details: [`docs/benchmark-howto.md`](docs/benchmark-howto.md).

#### Full matrix (EHS + Full vs everyone)

Runs all 10 pairings in one command:

```bash
# Quick preview
python3 v5.py --hands 100

# Better signal
python3 v5.py --hands 500

# Production run
python3 v5.py --hands 5000
python3 v5.py --parallel --jobs 4 --hands 5000
```

#### Subset previews

```bash
# FullAgent matchups only (4 pairings)
python3 v5.py --focus-full --hands 100

# EHSAgent matchups only (4 pairings)
python3 v5.py --focus-ehs --hands 100

# Head-to-head only: EHS vs Full
python3 v5.py --focus-full --focus-ehs --hands 100
```

To cover both EHS and Full vs all opponents without the full 10-pairing matrix, run `--focus-full` and `--focus-ehs` separately (8 pairings total; EHS–Full appears in both).

#### Hand-by-hand review

```bash
python3 v5.py --hands 50 --hand-log
python3 v5.py --focus-full --focus-ehs --hands 20 --hand-log results/hand-logs/preview.txt
```

#### Save output

```bash
python3 v5.py --hands 500 2>&1 | tee results/behavior-agent-performance/preview-$(date +%Y%m%d).txt
```

#### Reading results

1. **Raw Results** — mbb/hand per pairing (positive = that seat won chips over the sample).
2. **Win-Rate Matrix** — compare the `EHSAgent` and `FullAgent` rows against the same column opponent. Example: Full should beat EHS vs RuleBased; EHS vs Full head-to-head is shown as `+Y` / `-Y` in the same column.
3. **FullAgent Opponent-Model Diagnostics** — end-of-session `VPIP`, `PFR`, `AF`, `FTR`, and applied adjustments.

Suggested preview ladder: `--hands 50` (sanity) → `--hands 500` (directional) → `--hands 5000` (production).

Note: `--smoke` runs TAG–LAG / Full–TAG / Full–LAG only and does **not** include EHS.

## Key Concepts

**mbb/hand** — milli-big-blinds per hand. The standard poker win-rate metric. 1000 mbb = 1 big blind profit per hand. Positive = winning, negative = losing.

**EHS (Effective Hand Strength)** — the probability your hand wins at showdown against a uniformly random opponent hand, given all cards still to come. Estimated by Monte Carlo simulation (default 500 samples during play).

**Pot odds** — the minimum win rate needed to break even on a call: `call_amount / (pot + call_amount)`. The EHS agent calls when `EHS > pot_odds` and raises when `EHS > pot_odds + 0.15`.
